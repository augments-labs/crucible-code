# Work clean-room

Learn from another harness's behaviour, architecture and documentation; never
copy its code, prompts, prose, art or other expression. Reconstruct an idea from
this project's own constraints and write it in this project's own words.

This is the one always-loaded rule because no lint or test can distinguish an
independently written implementation from copied expression. It applies before
a project file is opened, so no path scope can load it at the right time.
