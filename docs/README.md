# crucible

A terminal coding agent. You type a prompt; it reads, searches, edits and runs
things in the directory you started it in, and asks before anything that changes
a file or starts a process.

- [Getting started](getting-started.md) — install, a key, a first session.
- [Providers and models](providers.md) — `--model`, and which key is read.
- [Permission](permission.md) — what you are asked, and what each answer means.
- [Sessions](sessions.md) — where a session is kept, and `--continue`.

> **0.0.x is unstable.** Flags, session files and config may change in any 0.0.x
> release with no deprecation period. Nothing here is a compatibility promise
> until 0.1.0.
